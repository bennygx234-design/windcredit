# Your build list (do these yourself)

**Why this matters:** the 2026 rules say *"All coding and technical development must be done by the student,"* and AI *"must not constitute the entirety of the technical development."* Most of WindCredit's code so far was generated by an AI assistant. To enter honestly, and to score well on "Code", you need to write real parts of the app yourself, understand all of it, and disclose the AI use accurately.

**How to use AI from here on (within the rules):** ask it to *explain*, *review* your code, or give a *hint*. Type the code yourself. Commit often under your own name, with messages describing what you did. That history is your proof of personal effort if a judge asks.

Do them in order. Feature 1 alone is a strong, honest contribution.

---

## Feature 1: Roof-deck attachment and "I have an inspection report" (about 3–4 hours)

**Why it's worth it:** right now the engine always assumes the weakest roof-deck nailing ("A"), because only an attic inspection can tell. If an inspection shows deck "B", the credit for clips jumps from **34.6% to 57.8%**. This makes the estimate much more accurate for anyone who already has a report, which is the honest accuracy story for your video.

**What to build:**
1. In `Models/HomeModels.swift`, add `enum RoofDeck: String, Codable, CaseIterable, Identifiable` with cases `a`, `b`, `cd`, `notSure`, plus `title`, `detail`, and a `tableKey` returning `"A"`, `"B"`, `"CD"` (`notSure` → `"A"`). Model it on `RoofToWall`.
2. Add `var roofDeck: RoofDeck? = nil` to `MitigationFeatures`. **Make it optional** so phones with older saved data still decode. Treat `nil` like `.notSure`.
3. In `Services/DiscountEngine.swift`, in `credit(for:newConstruction:terrain:)`, the key currently hard-codes `A`. Replace that with the deck's `tableKey`. Then update `best(_:_:)` so the stronger deck wins.
4. In `Views/Setup/ConfirmHomeView.swift`, add a toggle: **"I have a wind-mitigation report"**. When it's on, show a fifth question, "Roof deck attachment (question 3 on your report)", with A / B / C-D / Not sure cards. Reuse `ChoiceCard`. For the art, the `.roofAge` style (big text like "A", "B") is fine.
5. Write the tests yourself in `WindCreditTests.swift`:
   - Deck B + clips (other shape, no shutters, no SWR) should give **0.5781**. Check row 24 of the OIR spreadsheet, or `oir_b1_1699.json` key `nonFBC|B|clips|none|B|other|noswr`.
   - Deck `nil` should give exactly the same credit as deck A (no behavior change for everyone else).
   - `best()` should keep deck B over deck A.

**Done when:** `⌘U` is all green, and in the Simulator, choosing deck B on the sample home raises the estimate.

## Feature 2: Field-test log, your proof (about 3 hours, or use a spreadsheet)

**Why:** CoFIS (a 2025 national Top App) showed "90% accuracy" against a real flood. Judges reward proof. You want a line like *"On 8 Boca homes with real inspection reports, WindCredit flagged a real missed discount in 6."*

**Minimum version (no code):** a spreadsheet with one row per home: address (street only), year built, what the owner answered in the app, the app's estimate, what the inspection report says, whether the missed discount was real (yes/no), and the actual premium change if known. This is completely fine for the video.

**App version (more impressive):** a "Field test" screen in Settings. Each entry stores the owner's answers, the app's range, and the inspector's answers (from Feature 1). It shows "features matched: X of Y" and "missed discount confirmed: N of M". Add **Export CSV** using `ShareLink`.

## Feature 3: Spanish (and ideally Haitian Creole) (about 2–4 hours plus a reviewer)

**Why:** a big share of Palm Beach County residents speak a language other than English at home. Verify the exact figure from the Census (ACS) before you say it on camera. A Spanish version is a strong *Impact* point.

**How:** in Xcode, File ▸ New ▸ File ▸ **String Catalog** (`Localizable.xcstrings`), build once so Xcode collects every `Text("…")` string, add Spanish, and translate. Have a fluent speaker check it. Test with Scheme ▸ Run ▸ Options ▸ App Language ▸ Spanish.
